# Figma Clone Frontend

- React
- Pnpm
- Node
- Custom ui kit

## Functional Requirements

- Custom imported ui kit
- Test ui kit with playwright + storybook
- Write integration tests
- Use canvas for drawing
- Implement file system (Sketch)

## Run

1. Copy `.env.example` to `.env` and adjust (backend url, port)
2. `pnpm install`
3. `pnpm dev`
